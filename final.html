IP 조회 서비스에도 접속 IP가 전달됩니다. 조회 실패 시 실패 상태만 저장하며 위치는 대략적입니다. 이 항목들도 30일 보관하며 거부해도 참여할 수 있습니다. 선택 동의 시 User-Agent, 화면·창 크기, 색심도, 언어, 시간대, 터치 지원 및 브라우저 제공 네트워크 추정치가 추가 저장됩니다. 선택 동의를 거부해도 설문 참여가 가능합니다. 쿠키, 설치 폰트·플러그인 목록, 추적용 지문 및 권한 데이터는 저장하지 않습니다. IP 조회·전체 URL 항목은 각각 선택 항목 일괄 동의 시에만 저장합니다. 보관 기간은 접수일로부터 30일이며 제작자가 만료 응답을 삭제합니다. 삭제 요청은 링크를 전달한 제작자에게 제출 ID와 함께 문의하십시오.

    제8조 (문의) 조사와 관련한 문의는 본 링크를 전달한 자에게 해 주시기 바랍니다.

    선택 정보 수집·이용 안내

    종료 화면 표시: 동의하여 전송하는 기기·네트워크·IP·지역·URL 정보를 종료 화면에 표시합니다. 화면 공유나 촬영 시 타인에게 노출될 수 있으므로 주의하십시오. 마지막 화면에는 제출 ID를 표시합니다. ID 표시는 저장 성공을 의미하지 않습니다.

    목적·저장 장소: 보안 교육 실험 및 설문 분석. 제작자의 Google Sheets에 저장하며 무작위 제출 ID와 연결됩니다. 기기·IP·URL의 조합으로 개인이 식별될 가능성이 있습니다.

    기기: User-Agent, 화면·창 크기, 색심도, 언어, 시간대, 터치 지원, CPU 논리 코어 수, 메모리 추정치, 픽셀 비율. 브라우저 미지원 시 빈칸이며 실제 사양을 보장하지 않습니다.

    배터리: 지원 브라우저에서 설문 시작 시 충전 여부, 잔량(%), 충전 완료·방전 예상 시간(초)을 1회 조회하여 종료 화면에 표시하고 Google Sheets에 30일 저장합니다. 미지원·조회 실패는 상태만 저장하며 무한대 또는 알 수 없는 예상 시간은 빈칸입니다. 실제 전원 연결 상태나 잔량을 보장하지 않습니다. 지속 감시는 하지 않습니다.

    네트워크: 브라우저 제공 연결 유형, 다운링크 속도·RTT 추정치. 실제 속도 측정 결과가 아닙니다.

    상세 포인터·표시 설정: 설문 영역 안에서 마우스·터치·펜의 이동·누름·해제·취소 이벤트, 입력 종류, 문항 번호, 시작 후 시점(ms), 설문 영역 상대좌표(0~1)를 기록합니다. 이동 이벤트는 최대 초당 4회, 전체 최대 160건이며 키 입력·텍스트·타 사이트 행동은 기록하지 않습니다. 다크 모드 선호 및 동작 줄이기 선호는 완료 시 1회 조회합니다. 선택 일괄 동의에 포함되며 Google Sheets에 30일 보관합니다. 마지막 답변 선택 즉시 서버 전송을 시작합니다. IP·배터리는 시작 시 미리 조회한 값을 사용하며 그때까지 조회가 끝나지 않았다면 unavailable 상태를 저장합니다. 개별 이벤트 데이터는 서버에 저장하고 종료 화면에는 건수와 표시 설정을 보여줍니다.

    행동: 설문 버튼 대상 분류, 스크롤 비율(최대 초당 1회), 문항 표시 시점. 최대 80건이며 입력 내용·다른 사이트 활동은 수집하지 않습니다. 상대 포인터 좌표는 위 상세 포인터 항목에 따라 수집합니다.

    IP: 설문 시작 시 ipwho.is에 접속하여 공인 IP, 국가·지역·도시·ISP를 조회합니다. 외부 서비스는 접속 IP를 받습니다. 중도 이탈해도 이미 조회 서비스에 전달된 정보는 회수되지 않습니다. 조회 실패 상태도 기록하며 위치는 집 주소가 아닌 추정 지역입니다. 외부 서비스의 별도 개인정보 처리는 해당 서비스 정책에 따릅니다.

    주소: 현재 전체 URL(쿼리·해시 포함)과 브라우저 제공 유입 주소를 각각 최대 4000자 저장합니다. 브라우저 정책으로 유입 주소가 제한될 수 있습니다. 비밀정보 없는 실험 URL만 사용하십시오. 행동 분석용 제한 URL·유입 사이트 출처도 저장합니다.

    제외: 쿠키 원문, 로그인 정보, 폰트·플러그인 목록, Canvas/WebGL/오디오 추적 지문, 카메라·마이크·클립보드·파일은 수집하지 않습니다.

    동의·철회: 이 체크박스는 위 선택 항목 전체를 켜거나 끕니다. 거부해도 설문에 참여할 수 있습니다. 시작 전에 체크를 해제하면 선택 항목을 수집하지 않습니다. 완료 전 페이지를 닫으면 답변의 시트 전송은 진행하지 않지만 이미 발생한 외부 접속은 취소되지 않습니다.

    보관: 접수 후 30일. 제작자가 setup을 실행하여 생성한 일일 자동 삭제 작업이 정상 작동해야 삭제됩니다. Sheets 버전 기록·백업과 외부 서비스 로그의 완전 삭제까지 보장하지 않습니다.

    참여자 삭제 요청: 마지막 화면의 제출 ID를 기록한 뒤 링크를 전달한 제작자에게 해당 ID의 삭제를 요청하십시오. ID가 없으면 삭제 대상 식별이 어려울 수 있습니다. 이 페이지에 자동 삭제 요청 기능은 없습니다.

    제작자 삭제 처리: 비공개 결과 시트 설문응답_v7에서 제출ID 열로 요청 ID를 검색하여 해당 행 전체를 삭제합니다. 기존 버전 탭과 별도 복사·내보내기 파일에도 같은 ID가 있는지 확인하여 삭제하고 처리 결과를 요청자에게 안내합니다. 버전 기록이나 외부 서비스 로그는 행 삭제만으로 지워지지 않습니다.

    연락 방법: 현재는 링크를 전달한 제작자에게 문의하는 방식입니다. 운영 전 제작자는 실제 연락처를 추가해야 합니다.

    같은 제출 ID의 요청은 최대 7회까지 각각 저장합니다. 통신 재시도도 횟수에 포함되므로 같은 응답이 여러 행에 저장될 수 있습니다. 제출 ID는 제출마다 무작위 생성되며 사용자별 7회 제한은 아닙니다.
